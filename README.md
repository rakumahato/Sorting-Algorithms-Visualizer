# Sorting-Algorithms-Visualizer Watch sorting algorithms in action with customizable speed and array sizes.
Multiple Algorithms Supported:
Bubble Sort
Selection Sort
Insertion Sort
Merge Sort
Quick Sort
Heap Sort
Real-Time Controls: Pause, resume, or restart the visualization at any point.
Custom Inputs: Generate random arrays or input your own data for sorting.
Algorithm Comparisons: View key metrics like time complexity, comparisons, and swaps for each algorithm.
Usage :-
Select a sorting algorithm from the dropdown menu.
Adjust the settings:
Array size
Visualization speed
Click "Start" to begin the visualization.
Observe the sorting process step by step.
Technologies Used :-
Frontend: HTML, CSS, JavaScript
